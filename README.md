# Dự án Mini-project: Vẽ UI và tạo trang HTML

## Phân vùng cấu trúc theo ảnh thiết kế:
- **header**: Tiêu đề hệ thống học tập.
- **nav**: Thanh menu điều hướng lộ trình bài học.
- **main**: Chứa ảnh phác thảo giao diện `assets/ui-sketch.png`, bảng tóm tắt và form đăng ký học viên.
- **footer**: Bản quyền môn học của Đỗ Phúc Khang.
